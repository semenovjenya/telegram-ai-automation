# Локальный парсер каналов

Упрощенный парсер для локального использования без БД/Redis.

## Установка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --require-hashes -r requirements.lock
```

## Настройка

1. Скопируйте доверенный файл сессии Telegram в эту папку и дайте ему нейтральное имя:
   ```bash
   cp /safe/local/path/account.session ./telegram.session
   ```

   Файл сессии дает доступ к Telegram-аккаунту. Не коммитьте, не публикуйте и не
   принимайте такие файлы из недоверенных источников.

2. Создайте локальный `.env` из примера:
   ```bash
   cp .env.example .env
   ```

   Укажите `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и относительный путь
   `TELEGRAM_SESSION`. Файл сессии должен оставаться внутри `parser_local`.

## Скрипты

### 1. `local_parser.py` - Полный анализ канала

Анализирует канал и собирает общую статистику с AI-анализом контента.

**Использование:**
```bash
python local_parser.py t.me/demo_analytics_channel
```

Результат сохраняется в `Logs/channels_analysis_YYYYMMDD_HHMMSS.csv`

**Формат результата:**

CSV файл содержит следующие колонки:
- `row_id` - уникальный ID строки
- `title` - название канала
- `username` - username канала
- `subscribers` - количество подписчиков
- `engagement_rate_percent` - процент вовлеченности
- `avg_reach_24h/48h/72h` - средний охват за период
- `posting_*` - метрики постинга
- `tag` - тип тега (format, tonality, patterns, ad_fit, audience, channel_summary, channel_topic, channel_bio_raw)
- `content` - содержимое тега
- И другие метрики...

### 2. `top_posts_analyzer.py` - Анализ топ постов по репостам

Анализирует посты канала и ранжирует их по количеству репостов, просмотров или engagement rate.

**Базовое использование:**
```bash
python top_posts_analyzer.py demo_analytics_channel
```

**С параметрами:**
```bash
# Анализ 500 постов, показать топ-20
python top_posts_analyzer.py demo_analytics_channel --limit 500 --top 20

# Только посты с минимум 10 репостами
python top_posts_analyzer.py demo_analytics_channel --min-forwards 10

# Сортировка по просмотрам
python top_posts_analyzer.py demo_analytics_channel --sort-by views

# Сортировка по engagement rate
python top_posts_analyzer.py demo_analytics_channel --sort-by engagement_rate

# Только JSON, без CSV
python top_posts_analyzer.py demo_analytics_channel --no-csv
```

**Параметры:**
- `channel` - канал для анализа (обязательный)
- `--limit` - максимальное количество постов (по умолчанию: 1000)
- `--top` - количество топ постов для отображения (по умолчанию: 10)
- `--min-forwards` - минимальное количество репостов для фильтрации (по умолчанию: 0)
- `--sort-by` - поле для сортировки: `forwards`, `views`, `engagement_rate` (по умолчанию: forwards)
- `--no-csv` - не сохранять CSV файл
- `--no-json` - не сохранять JSON файл

**Результаты:**

Скрипт создает два файла в папке `Logs/`:
- `top_posts_{channel}_{timestamp}.csv` - таблица с топ постами
- `top_posts_{channel}_{timestamp}.json` - полные данные в JSON формате

**Формат CSV:**

| rank | post_id | date | forwards | views | replies | reactions | engagement_rate | age_days | text_preview | has_photo | has_video | has_audio | url |
|------|---------|------|----------|-------|---------|-----------|-----------------|----------|--------------|-----------|-----------|-----------|-----|
| 1 | 1542 | 2024-12-01 18:30:00 | 247 | 8,932 | 23 | 156 | 47.99 | 3.2 | Анонс вечеринки... | ✓ | | | https://t.me/... |

**Что показывает скрипт:**

- Рейтинг постов по репостам
- Метаданные каждого поста (ID, дата, текст)
- Метрики (просмотры, репосты, ответы, реакции)
- Engagement rate (процент просмотров от подписчиков)
- Типы контента (фото, видео, аудио и т.д.)
- Ссылки на посты
- Статистику по всем постам

### 3. `top_posts_analyzer_L2.py` - Глубокий LLM анализ топ постов

**Глубокий анализ топ-20 самых репощенных постов за последний месяц через LLM (OpenAI).**

**Базовое использование:**
```bash
# Автоматический анализ последнего JSON файла
python top_posts_analyzer_L2.py
```

**С параметрами:**
```bash
# Указать конкретный JSON файл
python top_posts_analyzer_L2.py --json-path Logs/top_posts_example_YYYYMMDD_HHMMSS.json

# Анализ за последние 2 месяца, топ-30 постов
python top_posts_analyzer_L2.py --months 2 --top 30

# Изменить модель OpenAI
python top_posts_analyzer_L2.py --model gpt-4o-mini

# Изменить задержку между запросами (для rate limits)
python top_posts_analyzer_L2.py --delay 2.0

# Показать в отчете только топ-3 поста
python top_posts_analyzer_L2.py --report-top 3
```

**Параметры:**
- `--json-path` - путь к JSON файлу (по умолчанию: последний файл из `Logs/top_posts_*.json`)
- `--months` - количество месяцев для фильтрации (по умолчанию: 1)
- `--top` - количество топ постов для анализа (по умолчанию: 20)
- `--model` - модель OpenAI (по умолчанию: из конфига, обычно gpt-4o)
- `--delay` - задержка между запросами к OpenAI в секундах (по умолчанию: 1.0)
- `--report-top` - количество постов для вывода в консольный отчет (по умолчанию: 5)
- `--no-csv` - не сохранять CSV файл
- `--no-json` - не сохранять JSON файл

**Что делает скрипт:**

1. **Загружает данные** из последнего JSON файла с постами (или указанного файла)
2. **Фильтрует посты** за последний месяц (или указанный период)
3. **Выбирает топ-20** самых репощенных постов
4. **Анализирует каждый пост** через OpenAI LLM по следующим категориям:
   - Глубокий анализ содержания
   - Факторы вирусности
   - Целевая аудитория
   - Тип контента
   - Эмоциональная тональность
   - Рекомендации для улучшения
   - Предложения похожего контента

**Результаты:**

Скрипт создает два файла в папке `Logs/`:
- `llm_analysis_top_posts_{timestamp}.json` - полные данные анализа в JSON
- `llm_analysis_top_posts_{timestamp}.csv` - таблица с результатами анализа

**Формат CSV:**

| rank | post_id | date | forwards | views | content_type | emotional_tone | target_audience | viral_factors | content_analysis | recommendations | similar_content_suggestions | text_preview | url |
|------|---------|------|----------|-------|--------------|----------------|-----------------|---------------|------------------|-----------------|----------------------------|--------------|-----|
| 1 | 43853 | 2025-12-05 07:05:45 | 89 | 4277 | мем | юмор, ирония | молодежь | ... | ... | ... | ... | ... | ... |

**Требования:**

- OpenAI API ключ в переменной окружения `OPENAI_API_KEY` или локальном `.env`
- Установленные зависимости: `openai`, `python-dotenv`

**Примечания:**

- Анализ одного поста занимает ~2-3 секунды
- Для 20 постов потребуется ~40-60 секунд
- Скрипт автоматически делает задержки между запросами для соблюдения rate limits
- Используется полный текст поста (если доступен в JSON), иначе превью

**Пример workflow:**

```bash
# 1. Собрать 1000 постов
python top_posts_analyzer.py demo_analytics_channel --limit 1000

# 2. Запустить глубокий анализ топ-20 за последний месяц
python top_posts_analyzer_L2.py
```
